# Migration Risk Register

Risks identified before and during the public-site migration, with the control
actually applied. Status reflects the state at the end of the migration.

| #    | Risk                                                                                                                           | Likelihood                                                                                               | Impact                                                         | Control                                                                                                                                                                                                                        | Status                    |

## Residual risk accepted

- **Locale-driven dynamic rendering** (R-14). Deliberate, contained to the public
  site, and the reason the language does not flash.
- **The live hero sculpture is not migrated** (R-17). The stills carry the
  identity; the scene is a self-contained follow-up.
- **Public support and membership content still has no domain backing.** It lives
  in `content/` with honesty flags, exactly as upstream. Turning it into database
  rows is future use-case work, not migration scope.

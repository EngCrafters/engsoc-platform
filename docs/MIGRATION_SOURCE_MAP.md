decided about every component. Required because the upstream repository can keep
changing while the migration is in progress.

## Component and file mapping

Decision legend: **COPY** (portable as-is) · **ADAPT** (ported with changes) ·
**REWRITE** (same product intent, new implementation) · **WRAP** (needs a
translation layer) · **DISCARD** (not carried) · **DEFER** (legitimate, later).

## Final cutover

After this migration, `engsoc-platform` is the **sole** implementation source for
the integrated public site. There is no runtime dependency on the upstream
repository, no submodule and no subtree. Future public-site development happens
in `engsoc-platform` on feature branches; the upstream repository is not
archived or modified, because it belongs to its own owner.
